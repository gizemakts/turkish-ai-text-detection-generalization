# Data and partition metadata

The repository includes the text-free `study/` fold and near-duplicate cluster assignments used in the reported evaluations. The original ABSTRACT and NEWSPAPER corpora, external evaluation texts, and prepared model inputs are not distributed.

`abstract/` and `newspaper/` describe the constructed corpus. `external_raw/` and `external_prepared/` retain dataset-source and preparation metadata rather than full datasets. See [DATA_ACCESS.md](../DATA_ACCESS.md) for data-access and redistribution restrictions.
